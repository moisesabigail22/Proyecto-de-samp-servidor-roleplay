# Nova Roleplay

El gamemode sigue llamandose `rpgm`. No cambies `gamemode0 rpgm 1` en `server.cfg`.
El nombre visible del servidor es `Nova Roleplay`.

## Compilar en Windows

Ejecuta desde la carpeta principal:

```bat
compile-rpgm.bat
```

El BAT muestra `Compilando... X/180 segundos`, escribe `compile-rpgm.log` y corta si
`pawncc.exe` se queda trabado. Si vuelve a quedarse pegado, mueve la carpeta del
servidor a una ruta corta, por ejemplo:

```text
C:\NovaRP
```

Despues vuelve a ejecutar `compile-rpgm.bat`.
